## 一、D4 导入三类校验 —— 3/4 通过，1 项无法构造

接口：`POST /api/v1/imports/strategic-tasks/preview`，上传构造的 xlsx 实测。

| 用例 | 输入 | 实际返回 | 判定 |
|---|---|---|---|
| ① ID 不存在 | 内部ID=99999 | `内部 ID 99999 不存在（或已被删除），请核对导出表中的内部ID列` | ✅ |
| ② 跨部门 | ID=2039（属战略部）+ targetOrgId=42（保卫处） | `内部 ID 2039 属于其他部门，不能导入到「党委保卫部 \| 保卫处」，请核对导出表中的内部ID列` | ✅ |
| ③ 跨年度 | cycleId=7(2025) + ID=2039(2026) | 返回的是「属于其他部门」，**跨年度分支未被触发** | ⚠️ 无法构造 |
| ④ 非数字 | 内部ID=ABC | `内部ID 格式不正确（应为数字），请直接复制导出表中的内部ID列` | ✅ |

### ③ 为何触发不到

当前生产库 43 条指标全部 `ownerOrgId=35 / cycleId=4`，**无任何往年数据**；且战略部(35) 自身不可作为导入目标（参数校验直接 400）。因此「部门匹配但年度不匹配」的前置条件构造不出来，部门校验总是先命中。

**建议**
- 补一条往年测试数据（如 cycleId=7 下挂 orgId=42 的指标），再复测该分支；
- 或确认该分支已有单测覆盖（`BusinessImportApplicationServiceTest`）。
- 报错文案在代码中确认存在：`属于其他考核年度，请重新导出最新模板`。

## 五、附带发现（不在清单内，建议关注）

### 1. 🔴 `GET /api/v1/alerts/manual-levels` 返回 500

批量获取指标手动预警等级接口返回 HTTP 500。前端表格当前等级显示正常（可能未走此接口），但 Swagger 中该接口标注为前端使用。
**建议**：确认是死代码还是漏修接口。

### 2. 🟡 种子数据「基础性权重合计 = 200 / 100」超限

战略任务管理页顶部红色显示权重合计 200（30 + 170 两类），按业务规则应为 100。
若「发起审批」以合计 100 为前置条件，**当前这批计划会被卡住**。建议核对种子数据 `seed` 中的权重分配。
